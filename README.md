# PromptPal
*A beginner-friendly AI learning assistant.*

## About the Project
PromptPal is my personal learning project, built while exploring Generative AI, Large Language Models (LLMs), and full-stack development.

The goal is to create an AI-powered learning assistant that helps users understand topics through simple explanations and interactive learning features.

## Current Features
- Basic frontend interface built with HTML and CSS.
- Topic input and interactive button using JavaScript.
- Express backend server.
- GET and POST API endpoints.
- Frontend-backend communication using Fetch API.
- JSON data exchange.
- CORS configuration.
- API testing using Postman.

## Tech Stack
**Frontend**
- HTML
- CSS
- JavaScript

**Backend**
- Node.js
- Express.js

**Tools**
- Git and GitHub
- Postman
- VS Code

## Learning Journey
I'm building PromptPal step by step alongside learning about Generative AI and LLM development.
Each development milestone helps me understand the concepts by implementing them in a practical project.

## Project Status
Currently, the frontend and backend are connected successfully. The backend returns the submitted topic as a test response. Gemini integration is the next development milestone.
